## GitHub Pages procedure
1. Open repository Settings.
2. Open Pages.
3. Under Build and deployment choose **Deploy from a branch**.
4. Select `main` and `/ (root)`.
5. Save.
6. Wait for the Pages URL.
7. Open the URL in Safari on iPhone.
8. Use **Share → Add to Home Screen**.

## Verification checklist
- Page loads without external dependencies
- Hold button stages tree
- Sportsman and Pro modes are selectable
- Green release records reaction time
- Early release records red light
- Stats persist in browser storage
- Reset clears statistics
- Layout scales for iPhone
