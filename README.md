# Churchracersja Drag Tree

A mobile-first drag racing reaction trainer branded for Churchracersja.

## Features
- Sportsman .500 and Pro .400 tree modes
- Hold-to-stage / release-on-green interaction
- Reaction-time display
- Red-light tracking
- Best reaction time, run count, recent runs
- Local browser persistence with localStorage
- Synthesized tree sounds
- iPhone-friendly layout
- No external libraries required

## Run
Open `index.html` in a browser.

## iPhone
After the project is hosted, open it in Safari and use **Share → Add to Home Screen**.

## GitHub Pages
Open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
